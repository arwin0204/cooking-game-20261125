Sizzle & Serve is a tiny kitchen-rush game: grab ingredients from the pantry, chop them on the board, cook patties and noodles on the stove, plate the dish to match the order board, and serve it before the customer's patience runs out. Six original recipes, a lunch rush that grows faster every day, and fully procedural sound — all in plain static files with no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD / arrows to move, E to interact, and keys 1-8 to grab ingredients from the pantry.
